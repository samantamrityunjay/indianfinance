# indianfinance

> **Rewrite in progress.** Version 0.1.0 will be a stateless Python library for
> Indian market end-of-day (EOD) data from official sources (AMFI, NSE).

The 0.0.x API (`indianfinance.company` with `market_info()`, `historical_data()` and
`annual_report()`) has been removed from this repository. Release 0.0.2 on PyPI is
unchanged. See [CHANGELOG.md](CHANGELOG.md) for details.

Installation steps, examples and the documentation link arrive with release 0.1.0.
